## Standing rules that follow from these changes
1. A bulk-ISP regulator effect is reportable only if it beats expression-matched random genes (DC-05) after BH across regulators.
2. Treatment effects on TE load are tested with 06, not inferred from 05 (DC-07).
3. QC-dependent results are labelled inconclusive (DC-08).
4. Every reported number carries an interval, a test, or both, and raw p is shown next to FDR (DC-10, DC-12).
5. Between-phenotype comparisons use family-line random effects or family means, never fish-level fixed effects that ignore family (DC-12).

- **What it holds.** Downloads, reference, alignments, counts and the pipeline environment of the zebrafish validation (`docs/runs/2026-10-01_zebrafish_validation/RUN_RECORD.md`, section "Where things are").

They are unchanged, because that run is finished. A re-run from the archived copy needs `W` set to the new location. `docs/HANDOFF.md` also names the old path.
- **State of the old copy.** Still on the lab compute server when this page was written. It is removed only after this record is merged, on the author's word, and a dated line is then added below.
